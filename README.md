A simple Python number guessing game with attempt counter. Простая игра "Угадай число" с подсчетом попыток.
---------------------------------------------------------------
Игра «Угадай число» (Python)

📌 Возможности:

· Программа загадывает число (в данном случае 42).
· Пользователь вводит свой вариант.
· Программа дает подсказки («Больше!» или «Меньше!»).
· Ведется подсчет количества попыток.
· Цикл прерывается (команда break) только при правильном ответе.

🚀 Как запустить:

1. Скачайте файл guessing_game.py.
2. Запустите его через терминал: python guessing_game.py.
3. Вводите числа, пока не угадаете.
